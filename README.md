# 🎓 Student Manager – A React SPA

## 📌 Introduction
**Student Manager** is a single-page application (SPA) built using **React**. It allows users to add and edit student details through interactive forms. The app demonstrates the use of **React Router** for client-side routing and **React state management** for handling form data. It is a great example of building a dynamic and responsive form-based CRUD interface in a React environment.

## ✨ Features
- 📋 View list of students
- ➕ Add new student details
- ✏️ Edit existing student information
- 🚀 Seamless navigation using React Router
- 📄 Form validation and state management

## 🎯 Design Decisions or Assumptions
- Used React Router v6 for modern routing management
- Utilized `useState` and `useEffect` for form state and data handling
- Data is stored in local component state (or optionally in localStorage)
- No external backend or database integration in this version
